# LeetCodeLib

A library for solving LeetCode problems in Elixir.

这是作者使用 Elixir 编程语言解决一些 LeetCode 算法题的代码库.

众所周知, Elixir 是一门**函数式、动态类型、运行在 Erlang 虚拟机**上的编程语言, 其语法和特性与其他主流编程语言有很大不同. 这使得很多算法题的解法在 Elixir 中有着独特的实现方式.
